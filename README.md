# DeepCheck AI

**Explainable AI-Generated Image Detection with Vision Transformers and Spatial Attribution**

DeepCheck AI is a research-oriented system for detecting AI-generated images and providing interpretable visual and natural-language explanations of model predictions.

The project investigates how a pretrained Vision Transformer can be adapted for AI-image forensics, how well the detector generalises to images produced by previously unseen generators, and how spatial attribution can be used to make model decisions more interpretable.

---

## Research Motivation

Rapid advances in generative AI have made synthetic images increasingly realistic, creating challenges for automated detection systems.

A detector that performs well on images similar to its training data may not necessarily generalise to images generated by newer or previously unseen models.

DeepCheck therefore focuses on three closely related research problems:

- detection of AI-generated images,
- generalisation across different image-generation systems,
- interpretability of detector predictions.

The project also explores how visual attribution can be combined with a large language model to communicate model behaviour in a more accessible form.

---

## Research Overview

DeepCheck uses a fine-tuned **SigLIP Vision Transformer** as the image detector.

An uploaded image is analysed by the detector and classified as either:

- **Authentic**
- **AI-generated**

To provide additional interpretability, **Explainable AI** is incorporated into the inference pipeline.

A spatial attribution heatmap identifies image regions associated with the predicted class. The heatmap and original image are then provided to an **OpenAI multimodal language model**, which generates a concise natural-language interpretation of the highlighted regions.

The resulting system therefore combines:

```text
Image
  ↓
Vision Transformer Detector
  ↓
Prediction and Class Probabilities
  ↓
Spatial Attribution Heatmap
  ↓
Multimodal LLM Interpretation
  ↓
Explainable Prediction
```

## Research Contributions

The project explores several aspects of AI-generated image forensics:

### Vision Transformer-Based Detection

A pretrained SigLIP visual encoder was adapted for binary AI-generated image detection through task-specific fine-tuning.

### Cross-Dataset Generalisation

The detector was evaluated not only on held-out data from its training distribution but also on an independent external benchmark containing images from multiple contemporary AI-image generators.

This was used to investigate how well learned forensic representations transfer beyond the original training distribution.

### Generator-Level Analysis

Performance was examined across individual image-generation systems to investigate whether detection behaviour varies between different generative models.

### Explainable AI

Spatial attribution is used to identify image regions associated with detector predictions.

Rather than treating the classifier as a black box, DeepCheck provides a visual representation of where the model's internal evidence is concentrated.

### Natural-Language Interpretation

A multimodal LLM is used to translate detector-derived spatial attribution into a short human-readable explanation.

The LLM does not perform the classification itself; its role is to interpret the visual attribution generated from the detector.

## Explainability Pipeline

The explainability component operates after image classification.

```text
Uploaded Image
      ↓
Deep Learning Detector
      ↓
Predicted Class
      ↓
Spatial Attribution Heatmap
      ↓
Original Image + Heatmap
      ↓
Multimodal LLM
      ↓
Natural-Language Interpretation
```

The heatmap provides class-specific spatial attribution, highlighting regions whose internal model activations are associated with the prediction.

The original image allows the language model to identify the semantic content present within those highlighted regions.

The resulting explanation is therefore intended as an interpretation of detector-derived attribution rather than independent evidence that an image is authentic or AI-generated.

# Running DeepCheck Locally

## 1. Clone the Repository

```bash
git clone <repository-url>
cd AiImageDetection
```

---

## 2. Create the Backend Environment

Navigate to:

```bash
cd Backend
```

Create a virtual environment.

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

Install the Python dependencies:

```bash
pip install -r requirements.txt
```

---

## 3. Add the Trained Model

Place the trained detector checkpoint inside:

```text
Backend/models/
```

The trained model weights are not necessarily distributed directly with the repository because of their size.

---

## 4. Configure Environment Variables

Create:

```text
Backend/.env
```

Add the required OpenAI API key:

```env
OPENAI_API_KEY=YOUR_OPENAI_API_KEY
```

API keys and other credentials should never be committed to the repository.

---

## 5. Start the Backend

From the `Backend` directory:

```bash
uvicorn main:app --reload
```

The API should then be available at:

```text
http://127.0.0.1:8000
```

API documentation:

```text
http://127.0.0.1:8000/docs
```

---

## 6. Start the Frontend

Open a second terminal:

```bash
cd Frontend/ai-image-detector
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local address displayed by the React development server.

---

## Using DeepCheck

After opening the application:

1. Upload an image or select a sample image.
2. Start the analysis.
3. Inspect the predicted class and class probabilities.
4. Examine the spatial attribution heatmap.
5. Read the generated natural-language interpretation.

This allows the classifier output, visual attribution and semantic explanation to be inspected together.

## Future Research Directions

DeepCheck provides several directions for continued research.

### Robust Cross-Generator Detection

Investigating training strategies that generalise more effectively to previously unseen generative models and changing synthetic-image distributions.

### AI-Generated Content Localisation

Moving beyond image-level classification toward finer spatial localisation of regions containing generated or manipulated content.

### Transformer-Specific Explainability

Comparing attribution approaches designed specifically for Vision Transformers with conventional class-attribution techniques.

### Attribution Faithfulness

Evaluating whether highlighted regions genuinely influence detector predictions using perturbation-based evaluation methods.

### Multimodal Forensics

Investigating how visual forensic models and multimodal foundation models can be combined without allowing language models to introduce unsupported explanations.

### Image-to-Video Extension

Extending detection and localisation research from AI-generated still images toward temporally consistent generated or manipulated video.
